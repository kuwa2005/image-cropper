# Image Cropper

ブラウザで完結する画像トリミングツール。サーバーへの送信なし。

## 機能

- **画像入力**: ドラッグ&ドロップ、クリップボード貼り付け (Ctrl+V)、ファイル選択
- **アスペクト比プリセット**: 1:1, 16:9, 9:16, 4:3, 3:4
- **任意サイズ指定**: ピクセル単位で縦横比を指定
- **カスタムプリセット保存**: よく使う比率を名前付きで保存 (最大10件)
- **トリミング**: ドラッグで位置移動、ハンドルでリサイズ (アスペクト比固定)
- **ダウンロード**: PNG, JPEG, WebP形式対応、ファイル名に日時含む
- **クリップボードコピー**: トリミング画像をコピー
- **ダーク/ライトモード**: 電球アイコンで切替、設定をCookie保存
- **モバイル対応**: レスポンシブデザイン

## 使用方法

1. `index.html` をブラウザで開く
2. 画像をドロップ、またはCtrl+Vで貼り付け
3. アスペクト比を選択、または任意サイズを指定
4. トリミング枠をドラッグ/リサイズ
5. 「ダウンロード」で保存、または「クリップボードにコピー」

## 技術スタック

- HTML5 / CSS3 / JavaScript (vanilla)
- Canvas API (画像処理)
- Cookie (設定保存)
- 外部ライブラリ不使用

## セキュリティ

- 画像はサーバーに送信されず、すべてブラウザ内で処理
- XSS対策 (sanitizeText)
- Content-Security-Policy設定済み
- X-Frame-Options: DENY (クリックジャッキング対策)
